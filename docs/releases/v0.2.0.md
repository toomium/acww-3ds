## What's new

- **The web builder.** Choose your own dump of Animal Crossing: Wild World (USA, Rev 1) on the project's website
  and download a ZIP laid out for the SD card. Everything happens in your browser: your ROM is never uploaded.
- **A data pack instead of the ROM.** The builder makes `game.pak` from your ROM: its files, without the game's
  code. The port still reads a ROM (`game.nds`) if there is no `game.pak`.
- **A HOME Menu version.** `acww.cia` (install it once with FBI) puts the game on the HOME Menu with the icon from
  your ROM and opens it as its own application. It holds no game code: it opens `acww.3dsx` from the SD card, so an
  update is the new `acww.3dsx` alone. It needs Luma3DS.
- **The version in the log.** `log.txt` starts with the port's version: please include the file in bug reports.

## On the SD card

```
sdmc:/3ds/acww/acww.3dsx      the program
sdmc:/3ds/acww/game.pak       your ROM's files (the web builder's ZIP has it)
sdmc:/3ds/dspfirm.cdc         the 3DS's sound firmware, dumped from your own console
```

Your save (`game.sav`) from an earlier version stays as it is.

## Known issues

- The HOME Menu version's banner is a placeholder.
- Only the USA ROM (Rev 1) is supported. Other languages still work by hand (`ACWW_LANG` in `acww.cfg`, with the
  European ROM as `lang.nds`); the web builder no longer sets them up.
- Wireless play does not work.
