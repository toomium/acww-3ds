## What's new

- **Main screen on top.** A new option in the options page's Game group (`ACWW_MAIN_TOP`, off by default, takes
  effect at once). The town and the rooms stay on the upper screen: the pause menu opens and closes on the lower
  screen alone, over the sky, instead of swapping the screens. While the world is on top, the touch screen shows the
  sky and takes no touches there.
- **New Leaf controls.** A new option under Enhancements (`ACWW_NL_CONTROLS`, off by default): Y picks up items and
  pulls weeds, B only runs, X opens and closes the pockets. The map then has no key of its own.

## Fixed

- **Writing letters no longer crashes.** Typing a letter over several lines (also on the bulletin board) could crash
  the game in v0.2.0 (#6, fixed by #2).
- **No more running too fast on a New 3DS.** After a slow moment (a load) the game could run faster than normal for
  up to a second while it caught up. It now catches up at most two frames.

## Updating

Replace `acww.3dsx` on the SD card (`sdmc:/3ds/acww/`). `game.pak`, `acww.cfg` and your save stay as they are; the
HOME Menu version (`acww.cia`) doesn't need to be installed again. The web builder's ZIP has the new version too.

## Known issues

- On an Old 3DS the game still runs slower than on the DS (about 34 of 60 frames a second in town); making it faster
  is being worked on.
- The HOME Menu version's banner is a placeholder.
- Only the USA ROM (Rev 1) is supported. Other languages still work by hand (`ACWW_LANG` in `acww.cfg`, with the
  European ROM as `lang.nds`); the web builder doesn't set them up.
- Wireless play does not work.
